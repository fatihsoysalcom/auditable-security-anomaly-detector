# Auditable Security Anomaly Detector

This example demonstrates a small, auditable AI-like tool for security monitoring. It processes simulated login events and identifies anomalies based on simple, transparent rules. Crucially, when an anomaly is detected, the system provides a clear explanation of *why* it was flagged, illustrating the concept of auditability for critical security decisions.

## Language

`python`

## How to Run

Save the code as `main.py`. Run from your terminal: `python main.py`
